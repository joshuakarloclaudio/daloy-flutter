# Changelog

## 1.0.4 (Windows, Microsoft Store 1.0.4.0)

Changes since 1.0.0.0, the first Store build (2026-10-21).

### New
- Control a teammate's presentation from your phone: nearby presentations on the same Wi-Fi show up with one tap to join, and paired devices are remembered so you only enter the code once.
- Fix lyrics mid-service: edit any section's words and name from Present or the remote, and it saves to the song.
- Add or edit chords and lyrics straight from a line-up's setlist; songs without chords or lyrics offer a quick "Add" button.
- Windows 11: translucent acrylic sidebar that follows the app's light/dark theme (earlier Windows keeps solid fills).
- Practice: bar timeline and clock improvements.
- Refreshed dashboard, line-up covers and editing, Perform view and chord sheet; chord keyboard and chord syntax guide updates.

### Improved
- Smoother rendering on Windows (default rendering engine).
- More reliable syncing of edits across devices.
- Refined glass surfaces, filter pills, search fields and buttons on desktop.

### Version history
- 1.0.0.0: first Store build
- 1.0.2 / 1.0.3: Present remote and pairing, setlist editing, dashboard and Perform polish, Windows performance
- 1.0.4: acrylic window backdrop and desktop polish
